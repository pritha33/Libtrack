# LibTrack – Web-Based Library Management System

## Overview
LibTrack is a web-based library management system designed to digitize and automate core library operations.  
It provides separate dashboards and login systems for **students** and **administrators**, enabling efficient management of books, members, and transactions.  

The system demonstrates practical implementation of CRUD operations, relational database design, and business logic handling.  
By automating manual tasks, LibTrack reduces administrative workload, improves record accuracy, and offers a structured approach to library management.

---

## Features

### Student Dashboard
- Login and registration system  
- Browse available books and request issuance  
- Track issued books and fines  
- Simple and responsive interface  

### Admin Dashboard
- Manage books (add, edit, delete)  
- Manage users and membership records  
- Approve or reject book requests  
- Monitor issued books and overdue fines  
- Dashboard with basic statistics and recent activity  

---

## Scope of the Project
- Manage book details (title, author, category, quantity)  
- Manage library member information  
- Issue and return books with automatic availability updates  
- Record fines and payment status  
- Display basic statistics through an admin dashboard  

---

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server Environment:** XAMPP  

---

## Installation Guide
1. Install **XAMPP** and start Apache and MySQL services.  
2. Copy the project folder into the `htdocs` directory.  
3. Import the provided SQL file into **phpMyAdmin** to set up the database.  
4. Update database credentials in `config.php`.
